PC120 VIEWER — LOCAL USE

Double-click "Start PC120 Viewer.cmd".

The launcher starts the local map server and opens:
http://localhost:3000/

Keep the command window open while using the viewer. Close that window to stop it.

The viewer includes:
- PC120 proposed zoning
- Operative Unitary Plan zoning
- Height variation controls
- Walkable catchments
- Frequent transport corridors
- Withdrawal area
- Click-to-inspect zoning details
- Auckland centre shortcuts

The background basemap is loaded from CARTO, so an internet connection is required
for streets and place labels. The planning layers themselves are stored locally.
